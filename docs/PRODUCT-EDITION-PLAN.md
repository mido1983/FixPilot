# WP FixPilot editions

## Free
Diagnostics, health score, PHP monitoring, basic safe repairs, performance analysis, manual repair, limited profiler.

## Pro add-on
Auto Repair Workflow, Update Guard Pro, Conflict Resolution automation, automatic rollback, advanced WooCommerce repair, AI Repair, scheduled monitoring and multi-site fleet features.

The Free plugin must remain fully functional without loading dormant Pro-only code behind a license switch. Pro should be a separate add-on plugin.
